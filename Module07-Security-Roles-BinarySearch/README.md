Module 06: Creating Classes & Objects

This program is an update to the Bank Teller program from Module05. There are two distinct classes with their own role-based permissions: User and Admin.
  Users are allowed to search for an account by the account number or the account balance using Binary Search. Currently, this function only checks to see if the account exists. The feature to display the account information hasn't been fully implemented yet, but it will be in a future update.
  Admins are allowed to add/remove accounts and show all current accounts. To protect personal information, Users are not allowed to see all accounts.

Instructions: Compile BankTeller.cpp and BankUsers.cpp in the IDE of your choice and run the executable.
